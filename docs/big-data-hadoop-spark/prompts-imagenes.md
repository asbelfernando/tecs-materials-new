# Prompts para generar imágenes de la presentación

Estos prompts están pensados para generar imágenes con estilo académico, limpio, profesional y apto para diapositivas.

---

## 1. Big Data 5V
**Nombre sugerido:** `bigdata-5v.png`

Prompt:
> Infografía profesional y académica sobre las 5V de Big Data: Volumen, Velocidad, Variedad, Veracidad y Valor. Diseño limpio, moderno, colores sobrios, iconos tecnológicos, fondo claro, estilo para presentación universitaria, alta resolución, composición horizontal.

---

## 2. Arquitectura Hadoop
**Nombre sugerido:** `arquitectura-hadoop.png`

Prompt:
> Diagrama profesional de arquitectura Hadoop mostrando Client, NameNode y múltiples DataNodes conectados en red. Debe representar almacenamiento distribuido en bloques, replicación de datos y entorno de clúster. Estilo académico, minimalista, etiquetas claras, fondo claro, formato horizontal para diapositiva.

---

## 3. Flujo MapReduce
**Nombre sugerido:** `mapreduce-flow.png`

Prompt:
> Diagrama educativo del flujo MapReduce con etapas Input, Split, Map, Shuffle/Sort, Reduce y Output. Visual simple, moderno y pedagógico, con flechas y bloques diferenciados por color, adecuado para clase universitaria de Big Data, fondo blanco o claro.

---

## 4. Ecosistema Spark
**Nombre sugerido:** `spark-ecosystem.png`

Prompt:
> Infografía profesional del ecosistema Apache Spark mostrando Spark Core, Spark SQL, Structured Streaming, MLlib y GraphX alrededor del motor principal. Diseño limpio, moderno, orientado a docencia, con iconografía tecnológica y colores sobrios.

---

## 5. Arquitectura moderna de datos
**Nombre sugerido:** `datalake-pipeline.png`

Prompt:
> Diagrama de arquitectura moderna de datos con fuentes de datos, capa de ingesta, data lake, procesamiento con Spark, consumo en BI y machine learning. Estilo profesional, académico, nube y analítica, diseño horizontal para presentación.

---

## 6. Databricks notebook y procesamiento distribuido
**Nombre sugerido:** `databricks-workflow.png`

Prompt:
> Ilustración profesional de un flujo de trabajo en Databricks con notebook colaborativo, clúster de Spark, transformación de datos y panel de resultados. Estilo moderno, tecnológico, limpio y apto para una diapositiva educativa.

---

## Recomendaciones visuales
- usar formato horizontal 16:9
- mantener coherencia de colores
- evitar exceso de texto dentro de las imágenes
- priorizar claridad conceptual antes que detalle técnico extremo
