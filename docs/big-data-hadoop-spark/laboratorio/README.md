# Laboratorio: Desarrollo de Aplicaciones de Big Data con Spark en Databricks

## Duración
2 horas

## Objetivo
Construir un flujo básico de análisis de datos con PySpark en Databricks, desde la carga del dataset hasta la generación de resultados agregados.

## Resultados esperados
El estudiante podrá:
- leer datos desde un archivo CSV
- explorar un DataFrame
- limpiar y transformar datos
- calcular métricas agregadas
- guardar resultados
- responder preguntas del negocio

## Archivos de esta carpeta
- `guia-laboratorio.md`
- `notebook-databricks-big-data-hadoop-spark.py`
- `rubrica.md`
- `dataset/sample-retail-transactions.csv`

## Requisitos
- acceso a Databricks
- cluster activo
- archivo CSV cargado en el entorno
- nociones básicas de Python

## Escenario
Se analizarán transacciones de retail para identificar patrones de venta por categoría, ciudad y producto.
