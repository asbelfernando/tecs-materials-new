# Aplicaciones de Big Data con Hadoop y Spark

Material premium para una sesión de **4 horas**:

- **Teoría (2 horas):** Aplicaciones de Big Data con Hadoop y/o Spark
- **Laboratorio (2 horas):** Desarrollo de Aplicaciones de Big Data con Hadoop y/o Spark en Databricks

## Propósito

Este módulo introduce los fundamentos de Big Data y el ecosistema Hadoop/Spark, y luego lleva esos conceptos a la práctica mediante un laboratorio guiado en Databricks usando PySpark.

## Resultados de aprendizaje

Al finalizar, el estudiante será capaz de:

1. Explicar el concepto de Big Data y sus principales características.
2. Describir la arquitectura y componentes clave de Hadoop.
3. Comprender el funcionamiento general de Spark y su modelo de procesamiento distribuido.
4. Comparar Hadoop MapReduce con Spark en distintos escenarios.
5. Desarrollar un flujo básico de análisis de datos usando PySpark.
6. Ejecutar un notebook en Databricks para cargar, transformar, analizar y guardar resultados.

## Contenido del módulo

- `slides.md`: presentación teórica completa de 2 horas
- `prompts-imagenes.md`: prompts listos para generar imágenes académicas/profesionales
- `laboratorio/guia-laboratorio.md`: guía paso a paso del laboratorio
- `laboratorio/notebook-databricks-big-data-hadoop-spark.py`: notebook ejecutable en Databricks
- `laboratorio/rubrica.md`: rúbrica de evaluación sugerida
- `laboratorio/dataset/sample-retail-transactions.csv`: dataset de ejemplo
- `assets/README.md`: indicaciones sobre recursos visuales

## Sugerencia de uso en clase

### Bloque teórico (2 horas)
- 20 min: introducción a Big Data
- 25 min: Hadoop y HDFS
- 25 min: MapReduce
- 25 min: Spark y comparación con Hadoop
- 15 min: casos reales y discusión
- 10 min: cierre y transición

### Bloque práctico (2 horas)
- 20 min: preparación del entorno en Databricks
- 25 min: carga y exploración de datos
- 35 min: transformaciones y análisis
- 20 min: guardado de resultados
- 20 min: ejercicios y conclusiones

## Público objetivo

- Estudiantes de ingeniería de sistemas, software, ciencia de datos o afines
- Participantes con conocimientos básicos de programación y análisis de datos

## Requisitos técnicos

- Cuenta en Databricks
- Cluster activo con soporte Spark
- Dataset CSV cargado en DBFS o FileStore
- Conocimientos básicos de Python

## Recomendación para el docente

Se sugiere usar este material junto con:
- preguntas interactivas durante la exposición
- resolución guiada del notebook
- una discusión final sobre escalabilidad y arquitectura de datos moderna
